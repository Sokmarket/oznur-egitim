|---|---|---|

## Kurulum
1. Tüm dosyaları tek klasöre koy.
2. `index.html`'i tarayıcıda aç. Offline çalışır.
3. AI için ⚙ → Sağlayıcı → anahtar.

## PWA
`python -m http.server 8080` → Chrome "Ana ekrana ekle".
